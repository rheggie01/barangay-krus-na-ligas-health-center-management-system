# System Testing Evidence

This folder contains the capstone-ready testing structure for the Barangay Krus na Ligas Health Center Management System.

Use these documents together with the automated validation output generated by:

```powershell
.\scripts\testing\Invoke-FinalValidation.ps1
```

The testing evidence should truthfully distinguish between:

- automated regression tests,
- developer verification,
- system/integration validation,
- deployment/recovery checks,
- and future end-user or health-center UAT.

Do not describe synthetic/mock development data as LGU-provided data. The safe project wording is:

> Synthetic/mock dataset informed by publicly available DOH and Quezon City LGU health reports and surveillance statistics.

Development metrics from synthetic data are technical/developmental results and must not be presented as real-world clinical accuracy.
