STALE EMPTY MODEL FILES
-----------------------
The current repository contains these empty files:

backend/app/models/inventory.py
backend/app/models/medicine_inventory.py

Do NOT delete them blindly.

First run from the project root:

Get-ChildItem .\backend\app -Recurse -Filter *.py |
    Select-String "app\.models\.inventory|app\.models\.medicine_inventory"

If there is no legitimate import/output, remove them:

Remove-Item .\backend\app\models\inventory.py
Remove-Item .\backend\app\models\medicine_inventory.py

Then run the repository quality check.

LINE ENDINGS
------------
.gitattributes standardizes source files as LF and PowerShell scripts as
CRLF. This is intended to reduce future Windows LF/CRLF warnings and noisy
team diffs.
